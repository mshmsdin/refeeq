# استكمال استيراد الأسفار

**الهدف:** إدخال النصوص الناقصة ذات المصدر المحدد، مع حفظ أصل كل نص بوضوح.

**النهج:** مستورد محدد لكل سفر أو مصدر، مع فحص الوحدات على قاعدة مؤقتة قبل الاستعمال.

**القيود:** لا استبدال للبيانات، ولا نسبة نص عربي أو إنجليزي إلى شاهد جعزي؛ المستخدم أجاز النشر والاستيراد.

## ما أُنجز
- [x] أضف خيار استيراد مصدر منفرد، واختبر رفض الرمز غير المعروف.
- [x] أصلح قراءة رد ويكي مصدر؛ تحقق من ٤٢ أودًا و٥١٢ وحدة.
- [x] أضف تتمة دانيال بترتيب المصدر ٣، ١٣، ١٤؛ تحقق من ٢٠٧ أعداد.
- [x] أضف «تغسات» كتقسيم عربي من أمثال ٢٥–٣١؛ تحقق من ٧ فصول و٢٠٢ عدد، مع توضيح أنه ليس شاهداً جعزياً مستقلاً.
- [x] استورد الأوديات (٤٢ أوداً، ٥١٢ وحدة) وتتمة دانيال (٢٠٧ أعداد) وتغسات (٢٠٢ عدد) إلى قاعدة البيبل المستقلة الحية.
- [x] أضف إلى عزرا سوتوئيل الشاهد الإنجليزي الموازي 2 Esdras 3–14؛ أعيد ترقيمه إلى ١–١٢ مع توضيح أنه ليس نصاً جعزياً.
- [x] استورد شاهد الملك جيمس الموازي لابن سيراخ الإثيوبي محلياً وحياً؛ تحقق من ٥١ فصلاً و١٣٩٣ عدداً، ومن بقاء بيانات المصدر بعد إعادة تهيئة المخطط.
- [x] أضف مهلة لجلب المصادر واختبر انقطاع الطلبات المتوقفة.

## المتبقي
- يوسف بن غوريون الإثيوبي: لا تتوفر ترجمة إنجليزية عامة منشورة عن النص الجعزي؛ النسخة المصورة في المكتبة البريطانية ليست تفريغاً نصياً، وإعادة البناء الحديثة ليست مصدراً عاماً مرخصاً لإعادة النشر.
- قاعدة رفيق منفصلة عن قاعدة البيبل؛ بيانات الأسفار المضافة تخص النسخة المستقلة فقط.
