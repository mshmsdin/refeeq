# استكمال استيراد الأسفار

**الهدف:** إدخال النصوص الناقصة ذات المصدر المحدد، مع حفظ أصل كل نص بوضوح.

**النهج:** مستورد محدد لكل سفر أو مصدر، مع فحص الوحدات على قاعدة مؤقتة قبل الاستعمال.

**القيود:** لا استبدال للبيانات، ولا نسبة نص عربي أو إنجليزي إلى شاهد جعزي، ولا نشر قبل موافقة المستخدم.

## ما أُنجز
- [x] أضف خيار استيراد مصدر منفرد، واختبر رفض الرمز غير المعروف.
- [x] أصلح قراءة رد ويكي مصدر؛ تحقق من ٤٢ أودًا و٥١٢ وحدة.
- [x] أضف تتمة دانيال بترتيب المصدر ٣، ١٣، ١٤؛ تحقق من ٢٠٧ أعداد.
- [x] أضف «تغسات» كتقسيم عربي من أمثال ٢٥–٣١؛ تحقق من ٧ فصول و٢٠٢ عدد، مع توضيح أنه ليس شاهداً جعزياً مستقلاً.
- [x] أضف مهلة لجلب المصادر واختبر انقطاع الطلبات المتوقفة.

## المتبقي
- عزرا سوتوئيل، سيراخ الإثيوبي، ويوسف بن غوريون الإثيوبي: لم يُعثر على نص رقمي مفتوح يمكن استيراده ونسبته بثقة.
- قاعدة الموقع الحي لم تُحدّث؛ ملف قاعدة المشروع المحلي فارغ، وأداة إدارة الموقع لم تستجب عند محاولة قراءة التطبيقات.
- يلزم نشر التعديلات أولاً ثم تشغيل المستوردات المستهدفة على قاعدة الموقع وفحص واجهة الكتاب المقدس.
